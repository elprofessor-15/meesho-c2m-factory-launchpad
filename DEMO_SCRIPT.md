# Demo Script

1. Open `/today` and point out the due-today queue, sample-data notice, stock-after-reservations, and bounded production scenario.
2. Ask in Hindi: “Aaj kitne orders bhejne hain?” Review the returned sample records and follow the due-today route.
3. Open a ready-to-ship order, download its clearly marked DEMO label, and mark it packed. Confirm the preview; point out that this does not record courier handover.
4. Ask to set a product's stock to an exact count. Review the stock confirmation, confirm it, then verify on-hand, reserved, and available values.
5. Open Demand Plan, change planned exposure, and describe the P10–P90 scenario range, assumptions, and stock/capacity constraints. Save and reload the scenario.
6. Request a callback with a preferred time. Explain that this saves a support request and does not place a phone call.
7. Switch to Operations View, assign the saved request, add an outcome note and time spent, and mark it resolved.
8. Return to seller view and verify the same support status.

All records are synthetic. Forecast results are not calibrated on live performance. Provider speech is shown only after it has actually succeeded; otherwise use the visible text response.
