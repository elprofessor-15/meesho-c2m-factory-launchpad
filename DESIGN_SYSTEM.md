# Design System

The interface is an operational manufacturer workspace, not a consumer storefront. It uses the warm neutral canvas `#F7F5F2`, Meesho-inspired brand accent `#580A46`, ink `#262326`, muted text `#69636A`, structural border `#DED8DC`, and functional success, warning, and error colours.

IBM Plex Sans is the Latin UI font, with script-aware Noto Sans fallbacks. Numeric values use tabular alignment where possible. The scale uses compact 12px metadata, 14–15px operating text, 21px section headings, and 32px page headings. Spacing follows a 4px base; controls use 6px corners and bounded panels 8px.

Desktop uses a 224px seller rail and 64px header. Tablet navigation collapses; mobile uses a four-item bottom bar and persistent microphone entry point. Tables become compact stacked records on narrow viewports. The assistant is a docked panel on desktop and a full-height sheet on mobile.

Use Lucide icons only for functional controls. Avoid gradients, decorative shadows, ornamental cards, and colour-only states. Keyboard focus uses a visible high-contrast ring, reduced motion is respected, and all controls remain usable without microphone access.
